# тз Наценка за некратность и уровни покупателей

Расширение `ТестовоеЗаданиеПользователь`, версия 1.0.1.0. Ставится вместо полного `ТестовоеЗадание`. Оба сразу не подключают. Номенклатуру, цены и клиентов расширение само не создаёт.

Требования: УТ 11.5.27.101, платформа 8.5.1.1343.

## Установка

1. Конфигуратор → Конфигурация → Расширения конфигурации → Загрузить из файла `ТестовоеЗаданиеПользователь.cfe`. Обновить конфигурацию базы данных.
2. Снять безопасный режим и заново открыть Предприятие. При первой загрузке платформа включает флажок. Пока он стоит, нельзя расширить `УправлениеДоступомСлужебный` и нельзя включить привилегированный режим: не записывается состав сегмента и не регистрируется обработка наценки. В конфигураторе: Конфигурация → Расширения конфигурации → `ТестовоеЗаданиеПользователь` → снять «Безопасный режим». В предприятии: НСИ и администрирование → Печатные формы, отчеты и обработки → Расширения → снять «Безопасный режим».
3. Войти полноправным пользователем.

## Первоначальная настройка

«тз Наценки и уровни» → «тз Первоначальная настройка». Команда включает автоматические скидки в продажах, ставит процент 20, если он пустой, регистрирует внешнюю обработку из макета и создаёт скидку «Наценка за некратность упаковке» с действием на пустой склад. Повтор второй скидки не создаёт.

Дальше у клиента данные заводят вручную. Это основной путь.

1. В «тз Кратность продажи» указать кратность вида номенклатуры. Наценка считается, когда суммарное количество по номенклатуре и характеристике этой кратности не кратно.
2. Создать три вида цен и три типовых соглашения с сегментами. Вид цен соглашения — тот, с которым сравнивается цена уровня.
3. В «тз Соглашения уровней» на бронзовый, серебряный и золотой записать соглашение и вид цен. Сегмент берётся из соглашения этой записи.
4. При других автоматических скидках в корне — «тз Наценка поверх скидок (перестроить группы)». Команда спрашивает подтверждение.
5. «тз Уровни покупателей по ИНН» заполнить вручную или из CSV.

## Стенд

Только для проверки, не для клиента. Файл → Открыть → `тз_ЗаполнениеТестовыхДанных.epf` → «Заполнить». Флажок первоначальной настройки по умолчанию включён. Обработка создаёт фиксированные демонстрационные наименования и цены: виды «Обои (тест)» и «Брак и отходы (тест)», номенклатуру, три вида цен 1000/930/850, сегменты, соглашения, ИНН 7701000033 и двух клиентов. Затем поступление на оптовый склад без ордерной схемы, перемещение в склад кассы РМК и розничная цена 1000 в вид цен этой кассы. Повтор пишет «без изменений». Рабочее место РМК обработка не переключает. Менеджеру файл не открывать: профиль закрывает внешние обработки.

## Загрузка CSV

«тз Загрузить уровни по ИНН». Файл UTF-8 или Windows-1251, разделитель «точка с запятой». Строка заголовка `ИНН;Уровень` пропускается. Уровень: бронзовый, серебряный, золотой или 1, 2, 3. При записи контрагента уровень переносится партнёру, если он не задан вручную. Новый клиент без строки ИНН получает бронзовый.

## Роли

«тз Общие права» БСП добавляет сама во все профили с полными или базовыми правами. Отдельно менеджеру её не назначают. «тз Настройка наценки и уровней» даёт изменение регистров и команды уровня и загрузки ИНН. «тз Изменение наценки за некратность» пропускает контроль. Её включают в профиль групп доступа. Администратору она добавляется только из профиля, через дополнительные роли администратора. Первоначальная настройка и перестройка групп доступны только полноправному пользователю.

Процент потом меняется константой «тз Процент наценки за некратность».

## Ограничения

Партнёр без записи уровня остаётся на типовом подборе. Другое доступное соглашение менеджер выбрать может, цена строки сравнивается с ценой уровня. Отчёт о розничных продажах контролирует цену, не сумму наценки. Пробитый чек пишется в журнал без отказа. Перестройка групп меняет дерево скидок. Безопасный режим расширения должен быть снят. Создание клиента менеджеру закрывает типовой профиль «Менеджер по продажам», не это расширение.
