# Служебная диагностика

Эти обработки не входят в поставку `dist`. Их открывают из Конфигуратора или предприятия только при разборе цен и прав. В клиентскую базу их не ставят.

| Каталог | Назначение |
| --- | --- |
| `цены` | Чтение ключа цен и розничной цены РМК без записи документов. |
| `права` | Роли пользователя информационной базы и `ПравоДоступа` на объекты расширения. Запуск только под Admin: менеджеру внешние обработки закрыты. |
| `режим` | Чтение флажка безопасного режима подключённых расширений. |
