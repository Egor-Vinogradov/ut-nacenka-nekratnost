# Наценка за некратность и уровни покупателей

Репозиторий: https://github.com/Egor-Vinogradov/ut-nacenka-nekratnost.git

Расширения для УТ 11.5.27.101, платформа 8.5.1.1343. Вместе не подключают. Выгрузка типовой конфигурации `osn` в репозиторий не входит.

## Состав сдачи

Архивом передаются `ТестовоеЗаданиеПользователь.cfe`, `тз_ЗаполнениеТестовыхДанных.epf` и сопроводительная записка Word. Полная версия расширения — папка `TestZadanie`.

| Каталог | Что это |
| --- | --- |
| `TestZadanie` | Полная версия. Основная разработка и тестирование, команды стенда внутри расширения. |
| `TestZadanie_user` | Поставляемая версия без тестовых данных. |
| `epf_src` | Исходники внешней обработки расчёта наценки. В расширения она попадает макетом. |
| `epf_user_data` | Исходники обработки тестовых данных для поставляемой версии. |
| `scripts` | Сборка, загрузка в базы, служебная диагностика. |
| `docs` | Журнал разработки и сценарий полной версии. В архив сдачи не входит. |
| `dist` | Описание и сценарий пользовательской версии. Бинарные `.cfe` и `.epf` git не хранит. |
