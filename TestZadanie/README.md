# тз Наценка за некратность и уровни покупателей (полная версия)

Расширение `ТестовоеЗадание`, версия 1.1.0.0. Вместе с `ТестовоеЗаданиеПользователь` не ставят. Внутри есть команды, которые создают демонстрационные номенклатуру, цены, соглашения и клиентов.

Требования: УТ 11.5.27.101, платформа 8.5.1.1343.

## Установка

1. Конфигуратор → Конфигурация → Расширения конфигурации → Загрузить из файла `ТестовоеЗадание.cfe`. Обновить конфигурацию базы данных. Для этой копии репозитория то же делает `scripts\load.cmd` в базу `F:\1с\TestCoder\База`.
2. Снять безопасный режим и заново открыть Предприятие. При первой загрузке в базу платформа включает этот флажок. Пока он стоит, сеанс запрещает расширять модуль `УправлениеДоступомСлужебный`: роль обхода не добавляется администраторам. Код не может включить привилегированный режим, поэтому не записывает состав сегментов уровня и не регистрирует внешнюю обработку наценки. В конфигураторе: Конфигурация → Расширения конфигурации → `ТестовоеЗадание` → снять «Безопасный режим». В предприятии: НСИ и администрирование → Печатные формы, отчеты и обработки → Расширения → снять «Безопасный режим». Повторная загрузка файлов уже снятый флажок не включает.
3. Полноправным пользователем, по порядку, в разделе «тз Наценки и уровни»:
   1. «тз Настроить наценку за некратность» — процент 20, внешняя обработка, скидка, виды номенклатуры и кратность обоев.
   2. «тз Заполнить уровни и цены» — три вида цен, цены, сегменты, типовые соглашения, регистр уровней, три клиента. Константу отладки эта команда не включает.
   3. «тз Наценка поверх скидок (перестроить группы)» — только если в корне скидок есть другие автоматические скидки. Команда спрашивает подтверждение.

## Отладка контроля

Константа «тз Отладка контроля» по умолчанию `Ложь`. Чтобы включить, откройте её в разделе «тз Наценки и уровни» и установите `Истина`. Если её уже включил старый запуск команды заполнения, верните `Ложь`.

Пока константа истина, журнал регистрации получает событие `тз.НаценкаЗаНекратность`, уровень «Информация»:

- решение по строке: документ, номер строки, номенклатура, вид цен, источник (строка, соглашение, уровень, шапка), базовая цена, цена строки, итог;
- пропуск всего контроля, если доступна роль «тз Изменение наценки за некратность».

Запись «цена по виду цен не найдена» и предупреждение о уже пробитом чеке пишутся и при выключенной константе. Предупреждение пробитого чека — уровень «Предупреждение», отказ проведения не ставится.

## Роли

«тз Общие права» БСП добавляет сама в профили с полными правами, базовыми правами БСП или базовыми правами внешних пользователей. «тз Настройка наценки и уровней» — администратору настроек: изменение регистров и команды уровня и загрузки ИНН. «тз Изменение наценки за некратность» обходит контроль наценки и цены. Её назначают профилем групп доступа. Администратору она попадает только если роль есть в его профиле: расширение добавляет её в дополнительные роли администратора. После проверки снимите Admin из группы обхода и войдите снова.

## Загрузка CSV

Команда «тз Загрузить уровни по ИНН из CSV». Файл UTF-8 или Windows-1251. Первая строка `ИНН;Уровень` пропускается, если это не ИНН. Уровень: бронзовый, серебряный, золотой или 1, 2, 3. Пример строки: `7701000033;Золотой`.

## Ограничения

Вычисляемые цены регламент `ОбновлениеЦен` может пересчитать. Розничная цена РМК в вычисляемый вид записана напрямую. Отчёт о розничных продажах контролирует только цену, не сумму наценки. Пробитый чек пишется в журнал без отказа. Перестройка групп скидок меняет данные. Партнёр без записи уровня остаётся на типовом подборе. Менеджер может выбрать другое доступное соглашение, цена всё равно сравнивается с ценой уровня. Безопасный режим расширения должен быть снят.

Сценарий проверки: `docs\Сценарий_проверки_полное.md`.
