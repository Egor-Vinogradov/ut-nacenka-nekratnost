# Тестовое задание

Полное расширение `ТестовоеЗадание`. Вместе с `ТестовоеЗаданиеПользователь` не ставят.

## Установка

1. Загрузить расширение в базу и обновить конфигурацию базы (`scripts\load.cmd` для `F:\1с\TestCoder\База`).
2. Снять безопасный режим и заново открыть Предприятие. При первой загрузке в базу платформа включает этот флажок. Пока он стоит, сеанс запрещает расширять модуль `УправлениеДоступомСлужебный`: роль обхода не добавляется администраторам. Код расширения не может включить привилегированный режим, поэтому не записывает состав сегментов уровня и не регистрирует внешнюю обработку наценки. В конфигураторе: Конфигурация → Расширения конфигурации → `ТестовоеЗадание` → снять «Безопасный режим». В предприятии: НСИ и администрирование → Печатные формы, отчеты и обработки → Расширения → снять «Безопасный режим». Ключа DESIGNER для этого флажка нет. Повторная загрузка файлов уже снятый флажок не включает: это свойство расширения в базе, не в XML.
3. Полноправным пользователем выполнить «тз Заполнить уровни и цены» и команду настройки наценки, если стенд ещё пустой.
